⚡ Lead Intake — Deployment Guide

Step-by-step: Cloudflare Worker + Supabase + all lead sources. Your website is already on Cloudflare — this is fast.

1

Create the Supabase Table

One SQL statement — takes 60 seconds

1

Go to your Supabase project

Open supabase.com/dashboard → your project → SQL Editor

2

Paste and run the migration

Open the file cloudflare-worker/supabase/create_inbound_leads.sql — copy the entire contents and paste into the SQL Editor → click Run.

✓ Creates the inbound_leads table with all indexes and security policies already configured.
2

Deploy the Cloudflare Worker

Run 4 terminal commands — your site is already on Cloudflare so the account is ready

1

Install Wrangler (Cloudflare's deploy tool)

npm install -g wrangler
2

Login to Cloudflare

wrangler login

Opens browser → approve access → done.

3

Navigate to the worker folder

cd "/Users/admin/Downloads/Mission Control/cloudflare-worker"
4

Add your Supabase secrets (never stored in code)

npx wrangler secret put SUPABASE_URL
# Paste: https://idbyrtwdeeruiutoukct.supabase.co

npx wrangler secret put SUPABASE_KEY
# Paste your Supabase anon key
5

Deploy

npx wrangler deploy
✓ Uploaded saturn-lead-intake
✓ Published to https://saturn-lead-intake.YOUR-SUBDOMAIN.workers.dev
Your Worker is now live. Copy the URL — you'll use it in the next steps.
6

Optional: map to your domain

In Cloudflare dashboard → Workers & Pages → your worker → Triggers → Add Route:

workers.starmovers.ca/lead-intake*

Now your webhook URL looks clean: https://workers.starmovers.ca/lead-intake

🌐 Website Contact Form

Add this to your form's submit handler on starmovers.ca:

// In your website's form submit JS:
document.getElementById('contact-form').addEventListener('submit', async (e) => {
  e.preventDefault();
  const data = Object.fromEntries(new FormData(e.target));
  data.source = 'website_form';

  await fetch('https://saturn-lead-intake.YOUR-SUBDOMAIN.workers.dev/lead-intake', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(data)
  });

  // Show your normal thank-you message
});
Your form fields should have name, phone, email, and message as their name attributes.

Host Mission Control Privately on Cloudflare Pages

Move from your laptop to a private URL your whole team can access

1

Push Mission Control to a private GitHub repo

cd "/Users/admin/Downloads/Mission Control"
git init
git add .
git commit -m "Mission Control v1"
# Create a PRIVATE repo on github.com, then:
git remote add origin https://github.com/YOUR-USERNAME/mission-control.git
git push -u origin main
2

Connect to Cloudflare Pages

Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git → select your repo → Build settings: leave blank (static HTML) → Deploy.

3

Add custom domain

Pages → your project → Custom Domains → Add: mc.starmovers.ca

Since your domain is already on Cloudflare, DNS updates automatically.

4

Lock it with Cloudflare Access

Cloudflare Dashboard → Zero Trust → Access → Applications → Add an application → Self-hosted → URL: mc.starmovers.ca → Policy: Allow emails = your team's emails only.

✓ Anyone who visits mc.starmovers.ca without being on your approved list gets a login screen. They enter their email, get a one-time code, and are in. No passwords. You can revoke access in 10 seconds.
5

Future updates are automatic

Any time you push to GitHub, Cloudflare Pages auto-deploys within 60 seconds. Your team always has the latest version.
